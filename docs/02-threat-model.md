# OpenClaw Workbench 威胁模型

## 1. 保护对象

- 工作区源代码、未提交改动和构建产物
- OpenClaw 配置、模型凭据、SecretRef 和 MCP 凭据
- 终端命令及其输出
- Agent 会话、提示词、工具参数和审计记录
- 用户身份、设备身份、配对凭证和会话令牌

## 2. 信任边界

```text
[用户界面]
    │ schema 校验 + 会话权限
[Product Runtime]
    │ 策略、审批、审计、恢复
[OpenClaw Adapter]
    │ 版本锁定、协议转换
[OpenClaw Gateway / Agent]
    │
[工作区 / 终端 / MCP / 外部网络]
```

UI 不可信：任何来自浏览器、插件、MCP 或模型的字符串都按不可信输入处理。模型不是授权主体。授权只能来自用户策略和明确审批。

## 3. 主要威胁与控制措施

| 威胁 | 后果 | 第一版控制 |
|---|---|---|
| Prompt Injection | Agent 被诱导读取密钥或执行危险动作 | 外部内容标记、工具策略隔离、动作前预览和审批 |
| 模型误改代码 | 代码损坏、数据丢失 | 工作树检查、Patch hash、Diff 预览、原子应用、回滚点 |
| 恶意/失控命令 | 删除、泄露、破坏环境 | 命令分类、allowlist/denylist、独立审批、超时、取消、工作区沙箱 |
| MCP Server 恶意行为 | 读取文件、外传数据、启动子进程 | 显式注册、健康检查、工具级权限、进程树清理、调用审计 |
| 凭据泄露 | 模型账户、代码仓库或生产系统被盗用 | SecretRef/系统密钥存储、日志脱敏、禁止进入 prompt 和导出包 |
| Bridge 未授权接入 | 远程控制本机 | 第一版仅局域网、一次性配对、设备身份、短期会话、撤销 |
| 重放/会话劫持 | 重复执行已批准操作 | 操作 nonce、会话绑定、过期时间、操作状态机 |
| 配置并发覆盖 | 凭据或策略被覆盖 | base-hash guard、备份、迁移、冲突阻断 |
| 自动更新被劫持 | 执行恶意版本 | 签名校验、固定更新源、分阶段发布、失败回滚 |
| 诊断数据外泄 | 源码/密钥进入日志 | 默认脱敏、用户主动导出、内容范围预览 |

## 4. 不可接受默认值

- 默认监听公网地址
- 默认允许任意终端命令
- 默认启用未知 MCP Server
- 默认把 API Key 写入普通配置或日志
- 默认自动批准 Code、Terminal、External 动作
- 默认将整个工作区上传云端
- 默认自动安装 Skill、插件或 MCP
- 默认用浏览器 localStorage 持久化长期高权限令牌

## 5. 高风险动作状态机

```text
proposed → inspected → awaiting_approval → approved → executing → verified
                                      └→ denied
                         executing ──→ cancelled / timed_out / failed
                         failed ─────→ rollback_available
```

任何状态跳转都写审计事件。重复批准、过期批准、目标 hash 变化、工作区变化必须拒绝执行并重新预览。

## 6. 安全验收红线

- 能证明未授权设备不能建立控制会话。
- 能证明 Code 不能绕过 Patch 审批直接写文件。
- 能证明 Terminal 不能绕过命令策略直接执行。
- 能证明 Terminal 仅接受 argv，不启用 shell，cwd 不得逃逸工作区，且超时、取消、输出超限会终止进程组。
- 能证明命令必须先形成绑定 action 的提案并经明确审批，命令结果会进入对应终态，不会绕过审批直接执行。
- 能证明失败或取消不会留下孤儿进程。
- 能证明日志、诊断包和错误消息不含 API Key、Cookie、密码和完整 SecretRef 值。
- 能证明配置冲突不会静默覆盖他人修改。
- 能证明配置导入只接受工作区内 JSON、先备份再原子写入，且无独立审批不会改变文件；回滚只接受 Workbench 生成的备份 ID。
- 能证明 MCP 注册只写入脱敏元数据，默认禁用；命令、端点、环境变量值和工具名不能通过注入绕过 schema。
- 能证明 MCP 工具授权绑定当前注册配置哈希且需要独立审批；健康检查不会自动启动 Server 或调用工具。
- 能证明更新失败可恢复到上一版本。
